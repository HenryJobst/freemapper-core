# 0002. GPL-3.0-or-later

Date: 2026-11-09
Status: Accepted

## Context
All three apps are GPL-3.0-or-later. freemapper's symbol sets come from OpenOrienteering Mapper, which is GPL.

## Decision
Every crate is GPL-3.0-or-later. Third-party material keeps its licence and is listed with source and licence
in the crate that carries it.

## Consequences
- The apps can use every crate without a licence change.
- Cost if wrong: a non-GPL user of a crate would need a relicensing.

Source: the apps' licence ADRs; freemapper ADR on the OOM symbol sets.

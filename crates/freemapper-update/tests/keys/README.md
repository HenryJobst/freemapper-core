These key pairs are for tests only. A release build never accepts them: each app's key list (`App::keys`) holds that app's own public key, wherever the app keeps it (freemapper: `assets/update/minisign.pub`), and none of these. They have no password and their secret keys sit in the repository on purpose. They were made with `minisign -G -W -p <name>.pub -s <name>.key` (`test`, `second` for the rotation test, `other` as a key the list does not know), and the fixtures in `../fixtures` were signed with `minisign -S -s <name>.key -m manifest.json -x <file> -t "freemapper test fixture"`.
